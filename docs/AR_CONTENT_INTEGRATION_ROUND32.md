# تقرير تكامل المحتوى – خزائن الهدى

## ما تم دمجه في هذا الإصدار

### الروايات والأحاديث
- ربط شاشة `/hadith` بواجهة Thaqalayn REST العامة.
- نقاط الربط المستخدمة: `/allbooks`، `/query?q=...`، `/query/{bookId}?q=...`، `/random`، `/{bookId}/random`، و`/{bookId}/{id}`.
- البحث يقبل العربية والإنجليزية، ويمكن تقييده بكتاب واحد.
- فهرس الكتب وآخر مجموعة روايات تم جلبها يُحفظان على الجهاز لتقليل الاعتماد على الاتصال.
- أضيفت قراءة متسلسلة للروايات داخل نطاق أرقام الكتاب الوارد في الفهرس.
- تظهر بيانات المصدر المتاحة فقط. التطبيق لا يستنتج صحة الرواية ولا ينشئ حكماً رجاليّاً أو حديثيّاً غير موجود في المصدر. يجب مراجعة شروط محتوى النصوص والترجمات قبل النشر التجاري أو إعادة توزيع مجموعات كبيرة منها.
- تظهر النصوص المحلية الحالية عبر `/hadith/local` عند الحاجة إلى القراءة دون اتصال.

المصدر التقني: https://www.thaqalayn-api.net/  
توثيق نقاط الربط: https://www.thaqalayn-api.net/api-docs/  
مستودع المشروع: https://github.com/MohammedArab1/ThaqalaynAPI

## مصادر إضافية قيد التقييم

### Rewayaat
يعلن موقع Rewayaat عن واجهة عامة مجانية لسجلات الروايات والرواة، ويذكر أن قاعدة الموقع تضم أكثر من 50 ألف رواية من 21 كتاباً. لم يتم تثبيت مسارات REST الخاصة به في هذا الإصدار لأن مخطط OpenAPI/الاستجابة لم يُتحقق منه عملياً ضمن بيئة البناء؛ لذلك لم تتم إضافة مسارات متخيلة. يمكن ضمه كمصدر ثانٍ بعد تثبيت مساراته وحقول النص العربي والرواة ومصدر كل رواية واختبارها.

- الموقع: https://rewayaat.info/ar
- معلومات المشروع وواجهة المطورين: https://rewayaat.info/ar/about
- المستودع: https://github.com/rewayaat/rewayaat

### الصوتيات
Rawda وShiaTunes مصدران يستحقان التواصل مع أصحابهما، لكن لم تُثبت وثائق API عامة أو إذن إعادة نشر للمقاطع. لم تتم إضافة كشّاطات غير رسمية أو روابط ملفات مباشرة غير مصرح بها. الصوتان الجديدان الخاصان بالمسبحة مُنشآن محلياً ومضمّنان داخل التطبيق، ولا يحتاجان إلى الإنترنت.

## مواقيت الصلاة وIslamicFinder
الرابط الذي أُرسل للمشروع يفتح صفحة HTML لمواقيت مدينة Api في ليسوتو، وليس نقطة REST موثّقة تُرجع JSON. الصفحة تعرض مواقيت مهيأة لطريقة الحساب ورقم الموقع المحددين فيها، ولا تصلح وحدها كمصدر مواقيت للعراق أو كواجهة API عامة. لذلك لم يُستبدل بها التكامل القائم. بقيت مصادر المواقيت الحالية في التطبيق (AlAdhan مع خيارات الحساب الموجودة، وبيانات/مصادر محلية أخرى) دون تعطيل.

رابط الصفحة محل الفحص: https://www.islamicfinder.org/ar/world/lesotho/44345994/api-prayer-times/

## دليل الزائر وخريطة العمل دون اتصال
- تمت إضافة دليل محلي داخل التطبيق بثمانية مواقع دينية بارزة وإحداثيات منشورة، مع بحث بالاسم والمدينة والمحافظة ونوع الموقع.
- تتضمن كل بطاقة رابط المصدر وحالة موثوقية الإحداثية، ويمكن نسخ الإحداثيات.
- خريطة العراق المضمنة رسم جغرافي مبسّط بنقاط مواقع، وتعمل دون إنترنت.
- هذه ليست خريطة شوارع أو نظام ملاحة، ولا تتضمن المسارات أو اتجاهات المنعطفات.
- هذه القائمة ليست سجلاً شاملاً لكل المراقد والجوامع والحسينيات في العراق. يلزم استيراد سجل شامل مرخّص من جهة رسمية أو من OpenStreetMap مع تدقيق ميداني، قبل وصفها بالشاملة.

## التنقل والأيقونات والمسبحة
- أضيف تبويب «الأقسام» إلى شريط التنقل السفلي، وأعيد ترتيب التبويبات بما يلائم الاستخدام العربي RTL.
- نُقلت شاشة القبلة إلى شبكة الأقسام بدلاً من شغل مساحة تبويب مستقل.
- جرى اختيار رموز Material Icons واضحة ومتوافقة مع مفاهيم الأقسام.
- أضيفت خيارات مظهر للعداد: أخضر، ذهبي، ليلي؛ وشكل دائري أو مستطيل ناعم.
- أضيف صوت نقرة ونغمة هادئة محليان، مع خيار تعطيل الصوت، والإبقاء على الاهتزاز كإعداد مستقل.

## حدود التحقق
لم يكن Flutter/Dart SDK متاحاً في بيئة تحرير هذا الأرشيف، لذلك لا يمكن الادعاء بأن `flutter analyze` أو `flutter test` أو بناء APK قد نُفّذ. يجب تشغيلها في بيئة Flutter فعلية قبل نشر نسخة المتجر. أُجريت فحوص JSON والأصول والاختبارات المتاحة للمكونات الخلفية.
