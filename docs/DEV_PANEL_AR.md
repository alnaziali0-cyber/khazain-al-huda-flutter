# لوحة المطوّر داخل التطبيق (خزائن الهدى)

> هذه اللوحة **داخل الهاتف** وهي منفصلة عن لوحة إدارة الخادم
> (`docs/DEVELOPER_PANEL_ACCESS_AR.md` تشرح تلك).

## طريقة الفتح (بلا أي أثر بصري)

| الطريقة | الإجراء |
|---|---|
| الضغط المطوّل | اضغط مطولاً على **شعار التطبيق** في الشريط السفلي **900 مللي ثانية** — تظهر حلقة تقدّم ذهبية أثناء الضغط، وتُفتح اللوحة عند إتمام المدة. |
| سبع نقرات | انقر على الشعار **7 مرات** خلال **3 ثوانٍ**. |
| ثلاث نقرات بإصبعين | انقر بإصبعين **3 مرات** على عنوان الشاشة. |

لا يوجد مسار `/developer`، ولا زر جرس، ولا قائمة مخفية في الإعدادات. اختبار
`test/app/no_developer_panel_route_test.dart` يفرض ذلك.

## رمز الدخول

* أربعة أرقام، تُنشأ عند أول فتح (تطلب التأكيد).
* تُخزَّن **مشفّرة**: ملح عشوائي 16 بايت + بصمة `SHA-256(salt:pin)`.
* لا يوجد نص صريح في الشيفرة ولا في واجهة المستخدم ولا في التخزين.
* يُقفل تلقائياً بعد **5 دقائق** من الخمول، وعند خروج التطبيق إلى الخلفية،
  وعند تدوير الجهاز. يوجد زر «قفل» في شريط اللوحة.

## التبويبات العشرة

| # | التبويب | ماذا يفعل |
|---|---|---|
| 1 | **التوكنات** | محرّر حيّ للألوان (24 رمزاً) والخطوط (7 خطوات) والزوايا والمسافات والشبكة. تصدير `tokens.json` / `tokens.css` / `tokens.ts` إلى ذاكرة التطبيق مع نسخها للحافظة. |
| 2 | **الأقسام** | تهيئة الكتالوج الافتراضي، إضافة، حذف، إعادة ترتيب، إخفاء، قفل، تبديل الأيقونة، وتعديل العنوان والمسار. |
| 3 | **الأيقونات** | 18 أيقونة SVG مع محرّر مسارات/سماكة/لون حيّ، وتصدير `icons.svg`. |
| 4 | **الخطوط** | الخطوط المضمّنة مع معاينة، ورفع TTF/OTF وتسجيله في الجهاز وقت التشغيل عبر `FontLoader`. |
| 5 | **المظهر** | داكن/فاتح/تلقائي، مقياس الخط، لون التمييز، مفتاح RTL/LTR (تشخيص)، مفتاح إظهار التشكيل، ومقياس النص الخطي المستقل. |
| 6 | **صورة→واجهة** | اختيار صورة مرجعية → استخراج الألوان (k-means، مع استثناء الرمادي والأبيض) → تقدير سلّم الخط والشبكة → مطابقة أقرب توكن (ΔE < 6 تحديث، وإلا توكن جديد) → معاينة قبل/بعد → بوابة تحقق → تطبيق الرقعة. |
| 7 | **النصوص** | إضافة وتعديل نصوص التطبيق داخل الجهاز. |
| 8 | **البيانات** | تهيئة، إعادة ضبط، تصدير، استيراد، نسخة احتياطية. |
| 9 | **التدقيق** | أيقونات مفقودة، عناوين مكرّرة، نصوص بديلة، نسبة تباين (WCAG AA)، وتجاوز الشبكة عند 320/360/412/768/1024 — مع إصلاح تلقائي. |
| 10 | **السجل** | سجل العمليات داخل اللوحة. |

## التخزين والتراجع

* الحالة تُحفظ في `SharedPreferences` تحت المفتاح **`khzain.dev.v1`** بصيغة JSON.
* كل تعديل يمرّ عبر `DevStoreController` (مُخزِّن حالة واحدة) مع **50 خطوة**
  تراجع/إعادة، وعند فشل أي عملية تُرجِع الحالة السابقة **بالكامل** قبل إعادة
  الخطأ.

## رقعة `UIPatch`

```jsonc
{
  "version": 1,
  "tokens":   { "colors": {}, "typography": {}, "radius": {}, "spacing": {}, "grid": {} },
  "sections": [ { "op": "add|update|remove|reorder", "section": {} } ],
  "layout":   [ { "route": "/", "tree": {} } ],
  "icons":    [ { "op": "add|update", "icon": {} } ],
  "strings":  { "key": "value" },
  "assets":   [ { "op": "add", "asset": {} } ]
}
```

نفس الصيغة تُنتجها أداة `tools/image-to-ui` (انظر README الخاص بها)، وتُقبل
في `DevStoreController.applyPatch(UIPatch)` مباشرة.

## حدود الأداة

* الاستخراج يعمل **داخل الجهاز** بالكامل (ألوان + تقدير خط + شبكة + مطابقة
  توكنات).
* **لا يولّد شيفرة مصدرية** من الصورة؛ الأداة الخارجية تُخرج رقعة `UIPatch`
  فقط، وبناء الشاشات يبقى يدوياً. هذا مذكور داخل التبويب نفسه.
