## لوحة المطوّر (مخفية)

تُفتح بالضغط المطوّل 900ms على شعار التطبيق في الشريط السفلي (مع حلقة تقدّم)،
أو بسبع نقرات على الشعار خلال ثلاث ثوانٍ، أو بثلاث نقرات بإصبعين على عنوان
الشاشة. بعد ذلك تُطلب رمز من أربعة أرقام يُحفظ مشفّراً (SHA-256 + ملح عشوائي).
لا يوجد أي مسار ظاهر أو زر جرس في التطبيق.

| التبويب | المحتوى |
|---|---|
| التوكنات | محرّر حيّ للألوان والخطوط والزوايا والمسافات والشبكة + تصدير `tokens.json` / `tokens.css` / `tokens.ts` |
| الأقسام | إضافة/حذف/إعادة ترتيب/إخفاء/قفل/تبديل أيقونة |
| الأيقونات | 18 أيقونة + محرّر مسارات/سماكة/لون + تصدير SVG |
| الخطوط | الخطوط المضمّنة + رفع TTF/OTF وتسجيله حيّاً |
| المظهر | داكن/فاتح/تلقائي + مقياس الخط + مفتاح RTL/LTR + لون التمييز + التشكيل |
| صورة→واجهة | استخراج الألوان وقياس الخط والشبكة + مطابقة أقرب توكن + معاينة قبل/بعد + بوابة تحقق |
| النصوص | تعديل النصوص داخل التطبيق |
| البيانات | تهيئة/إعادة ضبط/استيراد/تصدير/نسخة احتياطية |
| التدقيق | أيقونات مفقودة، عناوين مكررة، نصوص بديلة، تباين، تجاوز الشبكة + إصلاح تلقائي |
| السجل | سجل العمليات |

كل تعديل يمرّ عبر `DevStoreController` (مُخزِّن بحالة واحدة) مع تراجع/إعادة
حتى 50 خطوة، وإرجاع كامل للحالة السابقة عند فشل أي عملية.
