# تقرير الجولة 27 — المكتبة الصوتية

## المواصفات المعتمدة

- القرآن: فهرس السور الـ114.
- الحسينيات: تصنيف مستقل يشمل اللطميات والنواعي والقصائد والمجالس.
- الأذان: تصنيف مستقل متعدد التسجيلات والمؤذنين.
- بقية النطاق: الأدعية، الزيارات، المحاضرات، والإذاعات.
- طريقة التشغيل: بث للتسجيلات المنشورة، وتنزيل فقط عندما تسمح بيانات الحقوق بذلك.

## ما تم تطويره

1. شاشة مكتبة صوتية تتصل بواجهة الكتالوج العامة في الخادم.
2. مرشحات للأقسام السبعة، ومشغل `just_audio` للبث عبر HTTPS.
3. زر تنزيل يظهر حصراً إذا أعاد الخادم `can_download=true` ورابط تنزيل موثقاً.
4. حفظ التنزيلات المصرح بها داخل مساحة التطبيق الخاصة.
5. ربط قارئ السور بكتالوج الصوتيات المنشور، مع الإبقاء على تشغيل الملفات المحلية السابقة.
6. إضافة فهرس محلي لأسماء السور الـ114 وأعداد آياتها.
7. توثيق آلية إدخال التسجيلات في لوحة الإدارة وشروط نشرها وحقوقها.

## ما لم يُضمّن ولماذا

لم تُضمّن تسجيلات قرآن أو أذان أو لطميات أو مجالس فعلية في الأرشيف؛ لأن المصادر التي أمكن التحقق منها لا تمنح إذناً عاماً شاملاً لإعادة استضافة التسجيلات أو تنزيلها. وجود مشغل عام أو رابط MP3 لا يثبت حق إعادة التوزيع. لذلك تظهر الأقسام جاهزة لاستقبال التسجيلات الموثقة، ويظهر فهرس السور الـ114 مع حالة انتظار التسجيل المرخص بدلاً من إظهار أزرار تشغيل وهمية.

شروط Quran Foundation تسمح بعرض المحتوى ضمن تجربة التطبيق بشروط، لكنها تمنع توزيع محتوى QF أو بيانات API كحزمة مستقلة دون ترخيص تجاري مكتوب. كما تتطلب إبقاء أسرار API في الخادم. لا يُفعّل تنزيل أو تخزين صوت QF دون اتصال إلا وفق مسار التخزين المسموح في الشروط أو إذن مستقل.

## التحقق

- `services/api/tests/test_mobile_local_content_only.py`: 10 اختبارات ناجحة.
- فهرس السور: 114 مدخلاً، لكل منها رقم واسم عربي وعدد آيات وحالة انتظار التسجيل المرخص.
- فحص JSON: ناجح.
- فحص Python compileall: يجب تنفيذه ضمن حزمة الخادم قبل النشر.
- لم يتوفر Flutter/Dart SDK في بيئة التعديل؛ لذلك لم يُنفذ `flutter analyze` أو `flutter test` أو بناء APK.
- الاختبار الكامل السابق لواجهة API يتأثر بإعداد قاعدة بيانات الاختبار وحساب المشرف؛ ظهرت إخفاقات في مصادقة `test-owner` وعزل بيانات الأجهزة، وهي خارج تغييرات الصوتيات.

## شروط إكمال المكتبة بالمحتوى الفعلي

يجب إدخال كل تسجيل من لوحة الإدارة مع مصدر HTTPS، واسم صاحب الحق، ودليل إذن يغطي الاستخدام داخل التطبيق. لا يُفعّل البث دون `streaming_allowed`، ولا التنزيل دون `download_allowed` ورابط تنزيل، ولا التخزين دون اتصال دون `offline_cache_allowed`. يجب أن يحدد الإذن التسجيل المقصود ونطاق الاستخدام داخل تطبيق خزائن الهدى.
