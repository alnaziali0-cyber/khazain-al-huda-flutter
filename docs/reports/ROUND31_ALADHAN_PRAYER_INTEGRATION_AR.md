# الجولة 31 — دمج وحدة مواقيت الصلاة المرفوعة

## محتوى الملف المستلم

احتوى `prayer_times_module.zip` على `README_AR.md` و`prayer_times.js` فقط. يستخدم الملف JavaScript خدمة `https://api.aladhan.com/v1/timings`، ويعرض الفجر والشروق والظهر والعصر والغروب والمغرب والعشاء، ويستبعد الشروق من منطق الصلاة القادمة. طريقة المصدر الافتراضية هي `method=5`.

## طريقة الدمج

- تحويل المنطق إلى عميل Dart/Flutter باستخدام Dio، دون تضمين JavaScript داخل التطبيق.
- جلب تاريخ محدد عبر مسار `/v1/timings/DD-MM-YYYY` لتوفير بيانات اليوم وأيام جدول الإشعارات.
- الحفاظ على `method=5` كما في الملف المرفوع، وإضافة `method=0` خياراً جعفرياً وفق جدول طرق AlAdhan.
- إبقاء مصدر التطبيق الحالي افتراضياً، وعدم فرض المصدر الخارجي على المستخدم.
- إضافة اختيار مصدر من شاشة مواقيت الصلاة، وتنعكس النتيجة المختارة على بطاقة الرئيسية. أضيف زر «التفاصيل» في بطاقة الرئيسية لفتح شاشة المواقيت مباشرة والوصول إلى اختيار المصدر.
- ربط الاختيار بمزود تواريخ الصلاة المستخدم أيضاً في جدولة الإشعارات.
- طلب موافقة صريحة قبل إرسال الإحداثيات إلى `api.aladhan.com`، مع عميل HTTP منفصل لا يضيف معرّف الجهاز.
- استخدام كاش منفصل لكل مصدر وطريقة وموقع وتاريخ، وعدم التحول الصامت إلى طريقة حساب أخرى عند فشل الشبكة.
- دعم إحداثيات GPS المحفوظة حتى في حالة عدم اختيار مدينة أو محافظة، مع استمرار اشتراط الموافقة الصريحة على الإرسال.
- التحقق من تطابق التاريخ ورقم طريقة الحساب في استجابة الخدمة، واعتبار الغروب والإمساك ومنتصف الليل حقولاً إضافية اختيارية حتى لا يُرفض الرد الذي يحتوي على العناصر الأساسية التي تعرضها الوحدة المرفوعة.

## ملاحظات الحقوق والدقة

تصف وثائق AlAdhan الطريقة 0 بأنها جعفرية/اثنا عشرية والطريقة 5 بأنها الهيئة المصرية العامة للمساحة. لا تمثل أي نتيجة اعتماداً من مرجع ديني. يجب مقارنة المواقيت بجدول محلي معتمد قبل نشرها كمرجع للمستخدمين.

## نتائج التحقق وحدوده

- اختبارات Backend المركزة للمحتوى المحلي: 12 ناجحة.
- فحص ترجمة ملفات Python للخدمات: ناجح.
- تدقيق المشروع دون اتصال: JSON صالح 36/36، أرشيفات ZIP تالفة 0، وفحص حزم المصحف 10/10.
- أضيفت اختبارات Flutter لتطابق رد AlAdhan، والطريقتين 0 و5، وإحداثيات GPS، ورفض غياب الموافقة؛ لكنها لم تُشغّل لأن Flutter/Dart SDK غير متوفر في بيئة التعديل.
- مجلدا Android وiOS الأصليان غير متوفرين في نسخة المشروع، لذلك لم يتم بناء APK أو اختبار أذونات النظام على هاتف فعلي.
