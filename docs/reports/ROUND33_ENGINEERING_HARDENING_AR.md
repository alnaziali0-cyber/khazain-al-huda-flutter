# خزائن الهدى — تقرير التحسين الهندسي Round 33

## ما تم تغييره

- توسيع محلّل استجابات Thaqalayn v2 لعرض بيانات التصنيف والمجلد والمؤلف والمترجم، وحقول السند والمتن والتقييمات المنقولة عند توفرها.
- إضافة رابط الرواية الأصلي بعد التحقق من أن الرابط HTTPS ومضيفه ضمن نطاق `thaqalayn.net` فقط.
- إضافة زر لفتح المصدر الأصلي، ونسخ بيانات الإسناد والمرجع مع نص الرواية.
- جعل بيانات السند والتقييمات داخل قسم قابل للفتح حتى لا تطغى على متن الرواية.
- إضافة رسائل واجهة مفهومة عند HTTP 429 و404، وفحص `mounted` بعد العمليات غير المتزامنة قبل تحديث الشاشة.
- تقوية سلسلة حفظ المسبحة حتى لا يمنع فشل كتابة سابقة حفظ التحديثات اللاحقة.
- إضافة اختبارات نموذجية لحقول Thaqalayn الفعلية، واختبارات تحقق بيانات دليل الزائر المحلي.
- توسيع فاحص المشروع للتحقق من إحداثيات دليل الزائر، تفرّد المعرفات، أنواع المواقع، روابط HTTPS، وإظهار حدود التغطية وحدود الرسم الجغرافي بوضوح.
- إصلاح تهيئة اختبارات API وعزل قاعدة الاختبار، وتصحيح توقع عدد مراكز المدن ليطابق ملف البيانات الفعلي.

## حدود المصادر والبيانات

- الربط الحديثي يستخدم واجهة Thaqalayn v2 العامة؛ لا يتم نسخ قاعدة بياناتها كاملة إلى التطبيق.
- يجب احترام حدود الطلبات التي تفرضها الخدمة العامة، وتعرض الواجهة رسالة مستقلة عند استجابة HTTP 429.
- بيانات التقييمات تظهر كتقييمات منقولة من المصدر، ولا ينشئ التطبيق حكماً رجاليّاً أو حديثياً خاصاً به.
- دليل الزائر المضمّن هو عينة محلية أولية من مواقع بارزة، وليس فهرساً شاملاً لكل الحسينيات والجوامع والمراقد في العراق. يجب مراجعة الإحداثيات ميدانياً والحصول على مصادر رسمية/مرخّصة لتوسيع التغطية.
- الخريطة الحالية رسم جغرافي مبسّط بلا شبكة شوارع أو مسارات أو توجيه منعطفات؛ لذلك لا تُسوّق على أنها خرائط ملاحة كاملة.
- رابط IslamicFinder المقدم هو صفحة موقع لمواقيت الصلاة في Api / Lesotho، وليس عقد API JSON موثقاً للعراق؛ بقي مزود المواقيت العامل الموجود في المشروع دون استبدال تخميني.

## التحقق المنفّذ

- اختبارات خدمة Python API: 55 ناجحاً، 1 متجاوز، 0 إخفاقات في آخر تشغيل كامل.
- فحص Python bytecode compilation: ناجح.
- فحص JavaScript بواسطة `node --check`: ناجح.
- فحص أصول JSON وZIP وبصمات بيانات المصحف وأصول Flutter: ضمن `scripts/run_local_checks.sh`.
- لم يتوفر Flutter/Dart SDK في بيئة العمل هذه؛ لذلك لم يُنفّذ `flutter pub get` أو `flutter analyze` أو `flutter test`، ولم يُبنَ APK/IPA. كما أن مجلدي المنصتين `android/` و`ios/` غير موجودين في السورس الأصلي. يلزم استكمال هذه الخطوات في بيئة Flutter قبل النشر.
- استُثني ملفا SQLite المحليان `khazain_dev.db` من حزمة ZIP؛ فهما قواعد تطوير تحتوي حساب إدارة وجلسات ومفضلات اختبارية، وليسا ملفات مصدر أو ترحيلات لازمة للنشر. تُنشأ قاعدة التشغيل الجديدة من إعدادات البيئة وعمليات التهيئة والترحيل.
