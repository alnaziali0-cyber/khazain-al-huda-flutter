# تقرير فحص ودمج مكتبة صوت الشيعة — خزائن الهدى (Round 37)

## 1. تعريف الملف الأصلي

اسم الملف المستورد: `shiavoice-library-2026-11-22 (2).json`

الملف ليس API ولا أرشيفاً صوتياً. هو تصدير لحالة مكتبة/مشغل صوتيات متوافق مع موقع «صوت الشيعة»:
- `sv`: إصدار بنية التصدير 1.
- `exported`: 2026-11-22T21:46:23.262Z.
- `recent`: سجل آخر الاستماع، ويحتوي 26 عنصراً.
- `likes` و`likesMeta`: قوائم الإعجاب الفارغة.
- `playlists`: لا توجد قوائم محفوظة.
- `queue`: قائمة انتظار تحتوي عنصراً واحداً (`np16c`، «توادعنا»)، والفهرس 0، والتكرار متوقف، والخلط معطل.

تصنيف عرضي استُنتج من عناوين السجل فقط، وليس من تصنيف رسمي لكل تسجيل في موقع المصدر:

| القسم داخل التطبيق | العدد |
|---|---:|

الفحص البنيوي:
- جميع عناصر السجل لها معرّف فريد وعنوان وقارئ ومدة ورابط صفحة.
- جميع روابط صفحات التسجيل المستوردة من النمط النسبي `/play-{id}`.
- بيانات الصور المرجعية تشير إلى `shiavoice.com`.
- عولج السطر الجديد الزائد في نهاية عنوان «تسبيح الزهراء...» عند إنشاء نسخة العرض.
- حُذفت روابط المسار المباشر `/stream-*` من نسخة التطبيق عمداً؛ لم يتم تنزيل أي صوت أو حفظ ملف MP3.

## 3. قرار الدمج والحقوق

أُضيفت البيانات باعتبارها سجل استماع شخصياً مستورداً، لا باعتبارها API أو مكتبة كاملة. لا يثبت ملف التصدير وجود إذن لنسخ التسجيلات أو تنزيلها أو إعادة استضافتها؛ لذلك:
- يعرض التطبيق العنوان والقارئ والمدة والفئة.
- يفتح زر التسجيل صفحة المادة الأصلية على `https://shiavoice.com/play-{id}`.
- يمكن فتح صفحة القارئ فقط عندما يكون المسار مطابقاً للنمط الآمن `/@slug`.
- لا يوجد بث مباشر داخل مشغل خزائن الهدى، ولا تنزيل، ولا إعادة استضافة.
- أضيف تنبيه واضح بأن التطبيق غير تابع رسمياً للموقع.
- حالة المصدر في سجل المصادر: `reference_only_permission_for_reuse_unconfirmed`.

## 4. ما أُضيف إلى التطبيق

حُفظت نسخة التصدير الأصلية دون تعديل لأغراض التتبع في `docs/reference/imports/shiavoice_export_2026-11-22.json`، بينما يستخدم التطبيق ملف بيانات منقحاً لا يحتوي روابط البث المباشر.


1. ملف بيانات منظم:
   `apps/mobile/assets/data/catalogs/shiavoice_recent_library.json`
2. شاشة جديدة:
   `apps/mobile/lib/features/radio/shiavoice_library_screen.dart`
3. مسار جديد:
   `/shiavoice`
4. بطاقة قسم مستقلة في صفحة «الأقسام» بعنوان «مكتبة صوت الشيعة».
5. واجهة فهرس تحتوي:
   - آخر الاستماع.
   - القائمة الحالية.
   - المفضلة.
   - قوائم التشغيل.
   - البحث باسم التسجيل أو القارئ.
   - فلاتر القرآن والأذان والأدعية والقصائد/المقاطع.
6. تسجيل المصدر في كتالوج المصادر العام وكتالوج مراجع الصوتيات بصيغة رابط-فقط.
7. توثيق الدمج في README وإضافة اختبارات Python وFlutter للشاشة.
