# دمج Ahlul Bayt Treasures في خزائن الهدى

## هوية المصدر
- المستودع: https://github.com/KazTronics/AhlulBayt_Treasures
- الوصف في المستودع: مجموعة بيانات أدعية من أهل البيت للمطورين.
- الإصدار المُعتمد: `1.0.1`
- الالتزام المثبّت: `a59bd5f8fe078532622a08ea60c19d164fb425cb`
- الرخصة البرمجية للمستودع: MIT، ويجب إبقاء إشعار الرخصة عند إعادة توزيع أجزاء من البرنامج.
- يصف README بيانات النصوص بأنها Public Domain. لا يعني ذلك ثبوت نسبة كل نص أو صحة سنده.

## طريقة الدمج
- لا يوجد في المستودع عنوان REST API مستضاف؛ المحتوى عبارة عن ملفات بيانات ثابتة.
- يُجلب `duas_names.json` من raw.githubusercontent.com عند أول فتح لقسم الأدعية أو الزيارات.
- يُجلب `duas_data.jsonl` عند فتح نص بعينه، ثم يُبحث عن السجل بحسب `id`.
- يُحفظ الفهرس ومجموعة البيانات في مجلد دعم التطبيق مع فصل نسخة البيانات `1.0.1`.
- بعد التنزيل الأول، يُقرأ الفهرس والنصوص المفتوحة من النسخة المحلية عند انقطاع الإنترنت.
- استُخدم commit SHA ثابت بدلاً من `main` المتغير لضمان ثبات البيانات المعتمدة.

## حقول العرض
يقرأ التطبيق الحقول التالية كما وردت في مخطط README:
- `id`, `name`
- `rows[].index`
- `rows[].show_id` لعرض رقم المقطع فقط عندما لا تكون القيمة فارغة
- `rows[].arabic`
- `rows[].translation`
- `rows[].transliteration`
- `rows[].instruction` ويُعرض كتعليمات منفصلة وليس كنص مقروء
- `rows[].title` ويُعرض كعنوان فرعي

## حدود التوثيق
المجموعة مصدر بيانات نصية وليست حكماً رجاليّاً أو فقهياً. يحافظ التطبيق على النصوص والترجمات كما وردت في المصدر، ولا يضيف حكماً بالصحة أو الضعف، ولا يحوّل النصوص إلى فتاوى أو نسب قطعية. كما أن أسماء الفهرس الأصلية إنجليزية؛ تُعرض تسميات عربية داخلية لبعض العناوين المعروفة فقط، ويبقى الاسم الأصلي ظاهراً للمحافظة على قابلية المطابقة مع المصدر.
